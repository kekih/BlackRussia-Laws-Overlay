# Black Russia Laws Overlay

Крутое Android-приложение-оверлей для сервера **Black Russia** (RP).

## Возможности

- **Плавающий кружок** поверх всех окон (включая игру)
- Динамическое меню со **всеми твоими текстами**
- Если вкладок больше 3 — меню **прокручивается**
- Полноценный **редактор** внутри приложения:
  - Жирный, курсив
  - Цвет текста (7 цветов)
  - Размер текста
  - Заголовки
- **Добавляй сколько угодно** своих текстов (не только Законы и Правила)
- **Смена темы**: Тёмная / Светлая / Оранжевая
- Красивая иконка приложения
- Тексты сохраняются локально в JSON

## Как пользоваться

1. Установи APK
2. Открой приложение
3. Нажми **«Разрешение»** → дай разрешение «Поверх других приложений»
4. Нажми **«Старт»**
5. Появится оранжевый кружок с медведем — перетаскивай и нажимай

### Редактор
- На главном экране список всех текстов
- **+** (FAB) — создать новый
- Карандаш / тап по карточке — редактировать
- Корзина — удалить
- В редакторе: выдели текст → нажми **B / I / Цвет / Размер / Заголовок**

### Темы
Нажми иконку настроек в правом верхнем углу главного экрана.

## Сборка

```bash
git clone https://github.com/kekih/BlackRussia-Laws-Overlay.git
cd BlackRussia-Laws-Overlay
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

На GitHub Actions уже настроена автоматическая сборка при push в `main`.
